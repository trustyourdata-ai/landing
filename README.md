# TrustYourData.ai

Official website for [TrustYourData](https://trustyourdata.ai).

TrustYourData develops Task-Aware Dataset Readiness (TADR), a deterministic
framework for evaluating dataset readiness and identifying structural risks
before model training.

This repository contains the source code and public assets for the
TrustYourData.ai website.

## Website

https://trustyourdata.ai

## Repository Structure

The repository contains the static website implementation, including:

- the main TrustYourData landing page;
- public website assets;
- privacy information;
- terms and related public website pages.
